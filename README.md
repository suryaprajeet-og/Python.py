# Python Projects by Surya

A collection of menu-driven console applications built in Python.

| # | File | Description |
|---|------|-------------|
| 1 | `hotel_booking_system.py` | Hotel room booking, viewing, cancellation, and review system |
| 2 | `atm_system.py` | Simple ATM simulation |
| 3 | `smart_banking_assistant.py` | Function-based banking assistant |
| 4 | `student_management_system.py` | Function-based student record management |
| 5 | `expense_tracker.py` | Function-based personal expense tracker |
| 6 | `library_management_system.py` | Function-based library management system |
| 7 | `student_grade_management_system.py` | Function-based student grade management system |

## How to run

Each file is standalone. Run any one with:

```bash
python3 <filename>.py
```

For example:

```bash
python3 hotel_booking_system.py
```
